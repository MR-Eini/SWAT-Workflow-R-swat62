# SWAT workflow source

Source scripts from the supplied SWAT-Workflow-R archive, before the SWAT+ 62 update.
Upstream: https://github.com/biopsichas/SWAT-Workflow-R

This companion repository preserves the workflow scripts. Model data, observations,
GIS layers, executables and bundled R libraries remain in the original workspace.
The scripts retain their original relative paths and are intended as an overlay on
that workspace. The original upstream repository retains its own history.
